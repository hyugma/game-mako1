# Mako Action Game

HTML5 CanvasとモダンJavaScript (Vite) で作成された、シンプルな2D横スクロールアクションゲームです。

## 特徴
- PCおよびスマートフォン（タッチ操作）の両方に対応
- シンプルで直感的な操作性
- 進行距離に応じたスコアシステム
- パフォーマンスに優れたCanvas描画

## 操作方法

| デバイス | ジャンプ操作 |
| :--- | :--- |
| **PC** | `Space` キー または `↑` (上矢印) キー |
| **モバイル / タブレット** | 画面の任意の場所をタップ |

※ タイトル画面からのスタートや、ゲームオーバー時のリトライも同様の操作で可能です。

## ローカルでの実行方法

このプロジェクトはビルドツールとして [Vite](https://ja.vitejs.dev/) を使用しています。実行にはNode.jsのインストールが必要です。

1. **依存関係のインストール**
   プロジェクトのルートディレクトリで以下のコマンドを実行します。
   ```bash
   npm install
   ```

2. **開発サーバーの起動**
   ```bash
   npm run dev
   ```
   コマンド実行後、ターミナルに表示されるURL（通常は `http://localhost:5173` ）にブラウザでアクセスしてゲームをプレイできます。

## ビルド（本番環境用）

ゲームを本番環境向けに最適化してビルドするには、以下のコマンドを実行します。

```bash
npm run build
```

ビルドが完了すると、公開用のファイル一式が `dist` ディレクトリに出力されます。これを任意のウェブサーバー（GitHub Pages、Vercelなど）にデプロイしてください。

ローカルでビルド結果の動作確認を行いたい場合は、以下のコマンドを使用します。
```bash
npm run preview
```
